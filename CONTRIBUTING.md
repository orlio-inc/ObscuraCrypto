# Contributing

This repository does not accept pull requests, and pull requests opened against it will be closed without being merged.

It is published so that the encryption in Obscura Photo Vault can be read and checked, which only works if the code here stays the code the app ships. Changes are made by the app's developers.

What is welcome:

- **Security problems**: please report them privately, as described in [SECURITY.md](SECURITY.md), not in a public issue.
- **Questions and mistakes in the documentation**: open an issue.

You are free to fork, study and change this code under the terms of the [licence](LICENSE).
