# Reporting a security issue

Please report security problems privately, by email to support@orlio.io with "Security" in the subject line, rather than in a public issue. Include what you found, how to reproduce it, and what you believe the impact is.

You will get a reply within a few days. Please allow time for a fix to reach the App Store before publishing details.

Issues in scope are anything in this repository that would let someone read, alter or forge vault or media data without the password, weaken key derivation, or make the documented formats differ from what the code does.
